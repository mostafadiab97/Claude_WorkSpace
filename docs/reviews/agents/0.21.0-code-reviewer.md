## Checked, nothing found

- CRLF, BOM, `order: -0`, a 30-digit order number, `id` with trailing spaces: identical results in both functions (script above).
- Keys inside the text body after the header, indented keys under `links`: ignored by the fast path; identical results (`indented`, `crlf` cases).
- Compare numbers cache: staleness, session root reuse, old-version sessions, shared map mutation (R8).
- Save keeps numbers: new item (no `was`, so no keep), delete and move (not touched by this change, always renumber), external changes between revisions (refresh and saves share one queue, so no interleaving; an unsynced external edit does not bump the revision, and a later sync does).
- Re-entrancy of the pause in `versionView` (R9).
- `push`: odd branch names (only the tag-ambiguity case, R10), no upstream, remote `.`, pushRemote/pushDefault precedence (R10).
- Texts: the changes in `text.ts` and `text-ar.ts` are the same key in both languages. No new window call, no table change (no `FORMAT_VERSION` bump needed), no deep imports (`readStructure` is exported through `items/index.ts`).
