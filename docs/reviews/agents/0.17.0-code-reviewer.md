# Code review — 0.17.0 (1a structure)

Commit `8ef8e96`, changes since `v0.16.4` (review pack `docs/reviews/agents/0.17.0-pack.md`). **Scope:** what is new
in the core and window calls — documents as folders (`fileStore.ts`, `workspace.ts` createDocument/renameDocument,
`watcher.ts`, `structure.ts`, `itemOps.ts`, `compare.ts`, `gitOps.ts`), the incomplete filter (`sqliteIndex.ts`,
`items/validate.ts`), the Types window (`schemaFields.ts`, `writeSchemaTypes`, `TypesPanel.tsx`), the
`validate.ts`/`ipc.ts` checks, column drag and drop, and whether ARCHITECTURE / USER-GUIDE / ONBOARDING match the
code. I searched all of `src/` for code that still assumes one `items/` folder. `npm run check` is green (502 passed,
8 expected fail from the QA file that is not committed yet, coverage above the floor). The suspected defects were
checked with a throw-away vitest probe in the scratchpad (not in the repository), which drove the real workspace with
real Git: P1–P7 below. F = checked (code line, command or probe), I = likely (inferred, not run on Windows).

   numbers from 1), instead of mixing the top-level items of all documents (CR-22)? Recommended: group by document,
   the same in "Export all".
2. **Loose files into an existing document:** allow it (refusing when a file name is taken, CR-01), or only into a
   new document? Recommended: allow, refuse on a name clash and name the clashing files.

   the document shown above the table? Recommended: the document shown, or a choice when "All documents" is shown.

## Checked, nothing found

- Workspace queue: `createDocument`, `renameDocument` and `saveSchemaTypes` are wrapped in `q()` and call no other queued operation; `typeUsage` only reads.
- SQLite: no table change (document taken from `path`), so `FORMAT_VERSION` correctly stays the same; the misnamed-file SQL handles `Doc/ID.md` and loose `ID.md`.
- Incomplete SQL parameter order: correct for several types and for title/text mixed with fields; the window cannot send `required` (`validate.query` drops it; tested).
- Document filter SQL: `substr`/`length` both count characters, so non-Latin folder names work; `''` = no slash.
- Byte-wise order: `listDocuments`, `documentFolders` and `listItemFiles` now sort with `<`, not `localeCompare`.
- Window calls: `createDocument`, `renameDocument`, `getTypeUsage`, `saveSchemaTypes` each have a `ReqochetApi` method, a `Channels` entry and an `ipc.ts` handler with `validate.ts` checks (except CR-21); `newItem` checks `document`, and `defaultPath` checks it again with `isDocumentName` before any write.
- Path safety: document names refuse `/ \ : * ? " < > |`, control characters, a leading dot and a trailing dot or space; `from` must be in the folder list.
- Schema writes: `writeSchemaTypes` checks the schema revision (ConflictError), keeps unknown keys and comments of kept types (node reuse; tested), and validates before the atomic write; a used type cannot be removed (core check, not only the window).
- Rename commit: the message is the same in every language; uncommitted changes in the folder are refused first; the history follows (`git log --follow` tested); the rollback on a refused commit unstages and moves back.
- Module boundaries: new imports use module `index.ts` files only (ESLint green); the renderer uses only `window.reqochet` and shared types.
- Renderer: no hex/rgb in the changed CSS; logical properties only; new words come from `T` (ui-texts test green); the document choice is read when rendering, not stored in module constants.
- Column drag and drop: reorders only the movable columns, ignores drops that did not start in the list, keeps ↑/↓ for the keyboard.
