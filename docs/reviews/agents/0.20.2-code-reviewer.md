- W-07 compare rename split: different IDs give one deletion and one addition; the same ID or an unreadable side still takes the old path; QA W20-78 passes.
- W-03 merge: `sameItem` now sees link extras, so a change only to a link note is no longer ignored (the both-sides case is CR-04).

- W-06: `eachRow` without `includeEmpty` keeps row positions (`rows[n-1]`) and fills the gaps; the refusal text is in both languages; the test passes in under 5 s.
- W-08: `BULK_TIMEOUT` on add/commit/merge/restore/switch/reset; the max-buffer message is checked before the timeout message.

The root package has no install, prepare or postinstall script. The release job runs only on `refs/heads/main`.
