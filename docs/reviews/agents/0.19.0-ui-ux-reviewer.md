# UI/UX review (with accessibility) — 0.19.0

Scope: the screens the pack lists: compare / Changes view (D-19c: 13-compare, 10-changes-view, fixes-changes-view), an old version in the table (D-19b: history-0.19-version), the main column (D-19a: 02-hierarchy), and the Settings → Privacy diagram (privacy.png, privacy-dark.png, SettingsScreen.tsx). I looked at the screenshots and read the matching CSS and renderer lines. I did not run the app, so keyboard behaviour is inferred (I) from the code unless marked F. Light mode was seen in the screenshots; dark mode only for the diagram.

## Questions for the owner

1. The privacy diagram is a picture with English words only. In the Arabic window it stays English. Recommended: keep the picture for now and say so in the Arabic text under it; later, draw it in the renderer from the texts file so both languages and the high-contrast text come free. Alternative: make an Arabic pair of PNGs.
2. In an old version, should the editor hide the actions (Edit, Change..., Add link) or show them dimmed? Recommended: hide them (UX-07).

## Checked, nothing found

- Hard-coded colours in the new CSS blocks (D-19a/b/c): I saw only `--rm-*` tokens and `color-mix` of tokens in the blocks I read. No hex found.
- Read-only old version: the editor fieldset is `disabled` (ItemEditor.tsx:270), so inputs cannot be changed by keyboard. The banner has `role="status"` (WorkspaceScreen.tsx:338), a text tag "read-only" (not colour only), and a "Back to now" button.
- Changes view: tabs have `role="tablist"`, `aria-selected`; lists, regions and the checkboxes have `aria-label`s; the error and the pull notice use `role="alert"` / `role="status"`.
- Diff colours: removed and added text are not only red/green. They are also struck through and highlighted per word, and the rows carry an A/M letter badge, so colour is not the only meaning.
- Dark mode of the diagram: the dark picture is readable and matches the theme (both pictures swap with `.only-light/.only-dark`).
- Global focus ring: present (styles.css:38).
