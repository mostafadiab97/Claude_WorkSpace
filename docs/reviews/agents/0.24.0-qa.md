# QA report 0.24.0 (theme editor)

Scope: `fileTheme.ts` layers()/saveUser()/pickOverrides, `validate.ts` themeOverrides, `contrast.ts`. Hostile user files (bad JSON, array, comment keys, 6 MB, unknown modes/groups), CSS-special values, parallel saves, unwritable folder, input limits. New tests: `tests/qa-0.24.0-theme-editor-core.test.ts` (27 tests incl. 3 `it.fails`) and `tests/ui/qa-0.24.0-contrast.test.ts` (5 incl. 1 `it.fails`). All pass (it.fails = defect documented). Run: `npx vitest run <file>`.

| ID | file:line | severity | what is wrong (F = checked, I = likely) | suggested fix |
| --- | --- | --- | --- | --- |
| Q1 | src/modules/theme/fileTheme.ts:106 | Medium | F: temp file name is `theme.json.<pid>.tmp`, the same for every call. Two saveUser calls at once write the same tmp; the second `rename` fails (ENOENT) so one save rejects with a raw error. Test "two saves in parallel" (it.fails) shows `['fulfilled','rejected']`. The file is never corrupted. | Unique tmp name (pid + counter/random), or run saveUser through a small promise queue. |
| Q2 | src/modules/theme/fileTheme.ts:104, src/main/validate.ts:374-375 | Low | F: values are not checked for content: `url(http://…)`, `;`, `}` are accepted, saved and applied. They go through `style.setProperty` per variable, so no stylesheet injection, but `url()` in a background/font value can make the window request a remote file (offline-first, privacy). Test "should be refused" (it.fails). | Refuse `url(` / `@import` / `;` `{` `}` in values in themeOverrides and validateTheme (or only for colour tokens a hex check). |
| Q3 | src/modules/theme/defaults.ts:165 | Low | I: validateTheme's mergeGroup accepts arrays (typeof object), so a hand-edited `"spacing": ["1px"]` sets key `"0"`. Harmless in CSS; the editor view (pickOverrides) ignores arrays, so load and layers disagree. | Reject arrays in mergeGroup. |
| Q4 | src/renderer/src/lib/contrast.ts:5 | Low | F: `#rgba`/`#rrggbbaa` are valid CSS but not `isHexColour`; a colour with alpha gets no contrast warning (test it.fails). `contrastRatio` on bad input returns NaN, no throw; callers must check `isHexColour` first. | Parse alpha (blend over background) or document the skip; keep the guard. |
| Q5 | src/main/validate.ts:375 | Low | F: an empty string value makes the whole save throw ("must be a non-empty string"). The editor must drop cleared fields before sending (not tested in the UI here). | Skip empty values in themeOverrides, as pickOverrides does. |

## Questions for the owner
None.

## Checked, nothing found
- Invalid JSON, array/null/number/string user file: layers() gives `{}`, load() warns, saveUser replaces it.
- Comment-like keys (`//`, `_help`), `brand`, unknown groups survive saveUser; unknown modes dropped from the editor view.
- 6 MB user file reads fine.
- Folder that cannot be created: rejects, old file intact. Read-only folder: test skips when run as root (not exercised here).
- Leftover `.tmp` does not block the next save; empty overrides reset groups, keep notes.
- Input check: limits 200 values / 200 chars / 64-char keys, `__proto__` key, unknown mode/group, arrays, non-strings all refused as intended.
- contrastRatio: 21 and 1 extremes, #rgb equals #rrggbb, case/space tolerance.
