# QA tester report — 0.17.0 (1a structure)

Scope: documents as folders (odd names, folders created/deleted/moved by hand, duplicate IDs across documents, branch switch adding a document, renameDocument for a folder and for loose files, with and without Git, with uncommitted changes and a refused commit), the Types window rules in the core (used types, duplicate IDs, odd IDs, stale schema, required fields incl. title/text), and the "incomplete" filter combined with document, type, field, search, link and parent filters. Two new unit test files: `tests/qa-0.17.0-documents.test.ts` (34 tests) and `tests/qa-0.17.0-types.test.ts` (19 tests). Defects are written as `it.fails` (they pass today and turn red once fixed — then change them to `it`). `npm run check` is green (502 passed, 8 expected fail). Not covered: Playwright e2e (not run here), import into a chosen document and export of one document (the API has no document parameter for either, see questions).

## Questions for the owner

1. Import into a chosen document and export of one document: the import/export requests carry no document, so import goes to the default document and export always writes every document in one list (numbers restart per document). Should both get a "document" choice in 0.17.x or later?
2. A hand-moved file whose parent is in another document (QA-03): should reqochet drop the parent link silently on the next save, or only warn and let the user move it?

## Checked, nothing found

- Document names with spaces, Arabic, emoji, `_` and `%`: create, add item, document filter, counts; a name that is a prefix of another does not leak items.
- Refused names: empty, hidden, `..`, slashes, colon, `?`, control characters, 81 characters, case-only duplicate; padded names are trimmed.
- Folder created, filled and deleted by hand; all folders deleted (project still works, a new item recreates the folder); hidden folder and nested folder inside a document are not read.
- Same ID in two documents: reported ("2 files have the ID"), both files stay on disk.
- Branch switch that adds a document: shown after refresh.
- renameDocument: missing source, taken name, bad name, hidden source `.reqochet`, case-only rename, back-and-forth with `items`, empty (.gitkeep) document, loose tracked files in one commit, links across documents survive, nothing unrelated staged, uncommitted change refused, refused commit (pre-commit hook) restores folder and index.
- Types: used item and link type cannot be removed, last type cannot be removed, stale schema revision is a conflict and the outside edit is kept, odd type IDs refused by the window validator and by the core, duplicate IDs leave a valid file, YAML-special names round-trip, rename keeps items valid, comments and translations stay.
- Required fields: title/text/enum/list fields, whitespace-only, several types and fields in one query (parameter order), rule removed again, the window cannot send its own `required` map.
- Incomplete filter combined with document, type, field value, search text, links, parent, sort by number, paging and total.
