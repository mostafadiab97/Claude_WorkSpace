Scope: the changed main-process and core files (`src/main/ipc.ts`, `src/shared/api.ts`,
`src/modules/workspace/versionView.ts`, `workspace.ts`, `baselines.ts`), the item text now rendered as HTML in every
table row (`ItemTable.tsx` MainCell, `table/rows.ts`, `lib/markdown.ts`), and a check that dependencies, workflows and
Electron settings did not change. Commands run: `git diff v0.18.0..HEAD`, `npm audit --omit=dev` (0 problems), a
secret-pattern scan of the diff, a `git ls-tree` pathspec test, and a timing script that feeds hostile Markdown to the
same `marked` 18.1.3 settings the app uses (results below). "ReDoS" = text crafted so a parser takes very long.

## Checked, nothing found

- Window calls: `openVersion` validates its input with `v.commitRef` (exactly 40 hex characters, validate.ts:287), so no
  option or revision-expression injection; `closeVersion` takes no input. Channels entry and api method exist.
- Git commands: `rev-parse`, `ls-tree -r -z <commit> -- <dir>`, `cat-file --batch` all use argument arrays, no shell;
  `ls-tree` pathspec stops at the folder boundary (tested: `req` does not match `req2/`).
- Paths from Git trees: used only as keys inside the temporary index and as text on screen; no file is read or written
  with them; `.`-folders, README and deeper paths are excluded.
- Write guard: checked inside the queue at run time (race-free with the queued `openVersion`); every write and Git
  action in workspace.ts goes through `q`; non-queued calls (`newItem`, previews, history) do not write; an editor
  opened on a version gets revision `version:<commit>`, so a later save is conflict-checked, not overwritten.
- Temporary index file name: sha1 of the key, inside the cache folder; never a real project folder.
- Markdown to HTML: raw HTML is escaped, images show text only, only `https:`/`mailto:` links, href escaped; CSP blocks
  scripts; existing renderer tests lock this; link clicks open the browser via the window-open handler, no navigation.
- Electron settings, preload, `src/main/index.ts`: unchanged in this diff.
- Libraries: no change to package.json / package-lock.json; `npm audit --omit=dev` found 0 problems.
- Workflows: no change under `.github/`.
- Secrets: no token, key or password patterns in the diff (gitleaks not installed here; CI runs it).
- Personal data: none found in the changed files read.
