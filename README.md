# ReqMan

ReqMan (working name) is a local, Git-based requirements management tool — proof of concept.

Requirements live as plain-text files in a folder of a project's own Git repository; ReqMan is the
desktop GUI to view, edit, link, compare and export them. No server, no accounts.

- `samples/sample-requirements.xlsx` — fictional smart-thermostat requirements (59 items) for testing import/export
- `tools/make_sample_xlsx.py` — regenerates the sample file (`python tools/make_sample_xlsx.py samples/sample-requirements.xlsx`)

Design, requirements and decisions are recorded in the project analysis document.
