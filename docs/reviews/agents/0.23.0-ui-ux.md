## Questions for the owner

1. At narrow widths, should New item stay a bare "+" (current) or keep its word and let the search shrink?
2. Should the outline button get a word or a tree icon, since arrows can read as "sort"?

## Checked, nothing found

- Wide layout (1400 px): one row, search, icon group and New item aligned; matches Fable's proposed single row.
- New item panel: inside the window, focus ring visible, Create/Cancel clear, keyboard order top to bottom (I, from layout).
- Document menu: Delete is not colour-only (icon and word "Delete").
- Arabic: mirrored order of the bar, no overlap in the bar itself; top bar in Arabic at 1400 px fits.
- Ember: New item contrast (dark text on orange) is readable.
- DocumentBar.tsx: aria-labels exist on the rename input, merge group and merge select; the labels of the icon buttons were not searched in this run (only the file DocumentBar.tsx matched my pattern).
