## Checked, nothing found

- Window call rules: `wordTemplates` and the widened `setWindowIcon` have a `ReqochetApi` method, a `Channels` entry and an `ipc.ts` handler. Inputs are checked (`oneOf` for mode, `str` and path check for template and title).
- Template name cannot escape the folder: `validate.ts` refuses `/`, `\` and `..`, and `readTemplate` only takes a name found in the folder's listing.
- NFR-05: export writes no project files. The output goes through `writeFileAtomic`. No queue use is added, so there is no queued call inside another, and no new Git writes.
- HTML escaping: item text, titles, field values and attribute values are escaped (`esc`), and raw HTML in item text is shown as text. Link anchors only take ID-shaped strings.
- PDF window: hidden, `javascript: false`, sandboxed, no preload. The temporary folder is removed in `finally`, including on failure.
- Suspect flag in the trace table: the same rule as `traceability.ts` (confirmed fingerprint differs from the current one).
- Version view: `exportItems` uses the view context. `documentData` takes the real folder and the version's commit from the `<root>\0version\0<commit>` key.
- Title bar and mode: Light switches to a light bar, Dark and Ember to a dark bar, System to Windows. The renderer's System mode corrects itself after leaving a forced mode (its `prefers-color-scheme` listener is attached before the call returns). No other main-process code reads `nativeTheme`.
- Module boundaries: `exporting.ts` imports only from `../import-export` (index). `document.ts`, `header` and `cell` are exported through the module index or used inside the module.
- Texts: `T` is read inside functions only (document.ts, pdf.ts). No module-level text constants. Dialog words come from `T.exportDialog`.
- Order keys and SQLite: no order-key comparison changed (the only `localeCompare` is on ISO dates of baselines). No table change, so `FORMAT_VERSION` does not need a bump.
- Dependencies: `jszip` was already in `package.json` (MIT licence option, allowed for commercial use).
- USER-GUIDE placeholder table and template folder match the code (apart from C6).
