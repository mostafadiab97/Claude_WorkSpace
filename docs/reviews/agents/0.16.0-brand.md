# 0.16.0 brand review (fourth helper: brand / logo designer)

Frozen commit `28aef36` (built `out/`, not rebuilt). Rules checked: `resources/brand/README.md`, `brand-tokens.json`,
owner decisions `docs/reviews/done/2026-11-04-rename-reqochet.md` (R-03 … R-10). The logo drawings were not changed; every
proposal below changes only how the files are placed, and anything that would change a drawing goes back to the owner.

## How it was checked

- The built app was driven with Playwright Electron (the e2e harness helpers), a fresh repository and a copy of the
  10,005-item sandbox (so "opening" lasts long enough to watch the loading animation and the "thinking" eyes).
- Light, dark and Arabic; 100 % and device scale 1.5 (through the DevTools device-metrics override; the
  `--force-device-scale-factor` switch is ignored under Xvfb).
- Animation frames: top-bar eyes (8 frames, 0.75 s apart), start-screen eyes (6 frames, 1 s apart), the opening
  sequence (14 frames, 0.12 s apart), and three frames with reduced motion turned on.
- Screenshots and sketches are in the brand helper's scratch folder (not in the repository).
- Measured from the SVG drawings: the name is 4.32 : 1. Its "o" is 47 % of its height, so it is **12 px tall at 112 px
  wide** (top bar) and **26 px at 240 px** (start screen). The eyes move by 54–58 units. That is about **1 px at 28 px**
  (top bar) and about 3 px at 88 px (start screen).

## What already works well

- Only the package files are used. No name is set in a font, nothing is recoloured, no CSS filters are used, and the
  light or dark file follows the window's colour mode.
- Arabic: no logo, icon or animation is mirrored. The name stays in Latin letters, and the top-bar brand moves to the
  right side.
- Sizes are inside the rules: the top-bar name is 112 px (minimum 100), the start-screen name 240 px (160 or more), the
  splash 320 px and the opening animation 260 px (240–480). The face is the small cut below 32 px in light mode.
- **On the start screen, the q and o of the face and of the name are almost the same size** (28 px and 26 px). The
  face and the name therefore read as one family. Keep this ratio whatever size is chosen.
- Reduced motion works: with reduced motion turned on, three frames 0.9 s apart are pixel-identical. With
  `animation:none` the dots and pupils go back to their resting place, so nothing is left half-squashed or looking
  sideways.
- The Windows icon setting is correct: `win.icon` is `resources/brand/icon/reqochet.ico`, which holds 16, 20, 24, 32,
  40, 48, 64 and 256 px. NSIS takes it for the installer and the shortcut. The window has a native title bar, so
  Windows draws the 16 px small cut from the `.ico`.
- The idle eyes are charming and calm at 88 px: a glance left, then up-right, and a double blink. The blink can be read
  even at 28 px.

## Design advice (summary)

1. **One brand moment at a time.** The start screen is the brand's stage. While the app works, let the loading
   animation take that stage alone (BR-01).
2. **Make the face equally strong in light and dark.** At 28 px it needs the small cut in both modes (BR-02). This is
   the one asset gap in the package.
3. **Start screen size.** The face does not need to be larger. 88 px already dominates, especially in dark mode. Keep
   the face around 80–88 px and give the name a little more width (about 264 px). Then the name, not the tile, carries
   the screen, and the face's eyes line up with the q and o (BR-03).
4. **Thinking** reads well large and only faintly small. It is a nice touch, but it should not be the only busy
   signal (BR-07, BR-08).
5. **Arabic:** keep the face + name order fixed (BR-04). The owner decides.
