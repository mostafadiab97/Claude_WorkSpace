# QA report 0.23.0 — the bar above the table

Scope: MenuButton keyboard, `onToolbarKeyDown` / `rovingToolbar` (`lib/keys.ts`), the outline state (`rows.ts`), the new
workspace texts in five languages. One new test file, `tests/qa-0.23.0-toolbar-keys.test.ts` (41 tests). The project has
no jsdom (a fake browser for tests), so the DOM tests (28: toolbar keys, roving, MenuButton with real React) run only when
jsdom is found (`npm i --no-save jsdom`, or `QA_JSDOM_DIR=<folder holding node_modules/jsdom>`); otherwise they are
skipped. Run here with jsdom: 40 passed, 1 expected-fail (documents F-1). Without jsdom: 12 passed, 1 expected-fail,
28 skipped. ESLint clean; the file starts with `@ts-nocheck` because the tests tsconfig has no DOM types or JSX.
The outline tests replay the rule from `rows.ts` line 334 (it sits inside a hook, not exported), plus one test that
the source line is unchanged. Not covered: Toolbar.tsx / DocumentBar.tsx / NewItemButton panel as components, real
layout (jsdom has no `offsetParent`; the test fakes it from `hidden` / `display:none`), screenshots.
